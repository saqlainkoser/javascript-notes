## 1. HTTP Module

### What is it?

`http` is a **built-in core module** in Node.js. It lets you create web servers and make HTTP requests without installing anything. Frameworks like **Express**, **Koa**, and **Fastify** are all built on top of it.

```js
// CommonJS
const http = require('http');

// ES Modules
import http from 'http';
// or: import http from 'node:http';
```

### Key features

|Feature|Description|
|---|---|
|`http.createServer()`|Creates an HTTP server|
|`http.request()`|Makes an outgoing HTTP request|
|`http.get()`|Shortcut for GET requests|
|`http.STATUS_CODES`|Object mapping status codes to messages|
|`http.METHODS`|Array of supported HTTP methods|

```js
const http = require('http');

console.log(http.STATUS_CODES[404]); // "Not Found"
console.log(http.METHODS.slice(0, 5)); // [ 'ACL', 'BIND', 'CHECKOUT', 'CONNECT', 'COPY' ]
```

### Important classes

- **`http.Server`**: the server object (an `EventEmitter`).
- **`http.IncomingMessage`**: the `req` object (a readable stream).
- **`http.ServerResponse`**: the `res` object (a writable stream).

### Making a client request (bonus)

```js
const http = require('http');

http.get('http://example.com', (res) => {
  let data = '';
  res.on('data', (chunk) => (data += chunk));
  res.on('end', () => console.log(data));
}).on('error', (err) => console.error(err.message));
```

## 2. Request-Response Lifecycle

Every HTTP interaction follows the same cycle.

```
 Client (Browser)                              Node.js Server
       |                                             |
       |  1. TCP connection established              |
       |-------------------------------------------->|
       |  2. HTTP Request (method, URL, headers,     |
       |     body)                                   |
       |-------------------------------------------->|
       |                                             | 3. 'request' event fires
       |                                             | 4. Callback(req, res) runs
       |                                             | 5. Parse URL / headers / body
       |                                             | 6. Business logic (DB, files...)
       |  7. HTTP Response (status, headers, body)   |
       |<--------------------------------------------|
       |                                             | 8. res.end() completes response
       |  9. Connection closed / kept alive          |
```

### Step-by-step

1. **Client sends a request**: includes a method (`GET`, `POST`...), URL, headers, and optionally a body.
2. **Server receives it**: Node emits a `'request'` event.
3. **Callback runs** with two arguments: `req` and `res`.
4. **Server processes the request**: reads the URL, checks the method, reads the body, queries a database, etc.
5. **Server builds the response**: sets status code, headers, and body.
6. **Server ends the response** with `res.end()`. Without this call, the client hangs forever.

### The `req` object (IncomingMessage)

|Property|Meaning|Example|
|---|---|---|
|`req.method`|HTTP method|`'GET'`|
|`req.url`|Path + query string|`'/users?id=5'`|
|`req.headers`|Headers (lowercase keys)|`{ 'user-agent': '...' }`|
|`req.httpVersion`|HTTP version|`'1.1'`|
|`req.socket`|Underlying socket|`req.socket.remoteAddress`|

```js
const http = require('http');

http.createServer((req, res) => {
  console.log('Method :', req.method);
  console.log('URL    :', req.url);
  console.log('Headers:', req.headers);
  res.end('Logged!');
}).listen(3000);
```

### The `res` object (ServerResponse)

|Method|Purpose|
|---|---|
|`res.statusCode = 200`|Set status code|
|`res.setHeader(name, value)`|Set a single header|
|`res.writeHead(status, headers)`|Set status + headers together|
|`res.write(chunk)`|Send part of the body|
|`res.end([data])`|Finish the response (required)|

```js
res.writeHead(200, { 'Content-Type': 'text/plain' });
res.write('Hello, ');
res.write('World!');
res.end();
```

### Reading the request body (POST/PUT)

The body arrives in **chunks** because `req` is a stream.

```js
const http = require('http');

http.createServer((req, res) => {
  if (req.method === 'POST') {
    let body = '';

    req.on('data', (chunk) => {
      body += chunk.toString();
    });

    req.on('end', () => {
      console.log('Body received:', body);
      res.writeHead(200, { 'Content-Type': 'application/json' });
      res.end(JSON.stringify({ received: body }));
    });
  } else {
    res.end('Send a POST request');
  }
}).listen(3000);
```

Test it:

```bash
curl -X POST -d "name=Ali" http://localhost:3000
```

### Common HTTP status codes

|Code|Meaning|Use case|
|---|---|---|
|`200`|OK|Successful request|
|`201`|Created|Resource created (POST)|
|`204`|No Content|Success, nothing to return|
|`301/302`|Redirect|Moved permanently/temporarily|
|`400`|Bad Request|Invalid input|
|`401`|Unauthorized|Not authenticated|
|`403`|Forbidden|Not allowed|
|`404`|Not Found|Route/resource missing|
|`500`|Internal Server Error|Server crashed/bug|

### Common headers

```js
res.setHeader('Content-Type', 'text/html');          // HTML
res.setHeader('Content-Type', 'application/json');   // JSON
res.setHeader('Content-Type', 'text/plain');         // Plain text
res.setHeader('Access-Control-Allow-Origin', '*');   // CORS
res.setHeader('Set-Cookie', 'session=abc123; HttpOnly');
```

## 3. Creating an HTTP Server

### Minimal server

```js
const http = require('http');

const server = http.createServer((req, res) => {
  res.statusCode = 200;
  res.setHeader('Content-Type', 'text/plain');
  res.end('Hello, World!');
});

server.listen(3000, () => {
  console.log('Server running at http://localhost:3000');
});
```

Run it:

```bash
node server.js
```

Then open `http://localhost:3000` in your browser.

### How it works

- `http.createServer(callback)` returns a `Server` instance.
- The callback is executed **for every incoming request**.
- `server.listen(port, [host], [callback])` starts accepting connections.

### Alternative: using events

```js
const http = require('http');

const server = http.createServer();

server.on('request', (req, res) => {
  res.end('Handled via event');
});

server.on('listening', () => console.log('Listening...'));
server.on('error', (err) => console.error('Server error:', err.message));
server.on('close', () => console.log('Server closed'));

server.listen(3000);
```

### Sending different content types

**HTML**

```js
http.createServer((req, res) => {
  res.writeHead(200, { 'Content-Type': 'text/html' });
  res.end('<h1>Welcome</h1><p>This is HTML.</p>');
}).listen(3000);
```

**JSON**

```js
http.createServer((req, res) => {
  const data = { name: 'Ali', age: 22, skills: ['Node', 'JS'] };
  res.writeHead(200, { 'Content-Type': 'application/json' });
  res.end(JSON.stringify(data));
}).listen(3000);
```

**Serving an HTML file**

```js
const http = require('http');
const fs = require('fs');
const path = require('path');

http.createServer((req, res) => {
  const filePath = path.join(__dirname, 'index.html');

  fs.readFile(filePath, (err, content) => {
    if (err) {
      res.writeHead(500, { 'Content-Type': 'text/plain' });
      return res.end('Server Error');
    }
    res.writeHead(200, { 'Content-Type': 'text/html' });
    res.end(content);
  });
}).listen(3000);
```

**Streaming a file (better for large files)**

```js
const fs = require('fs');

http.createServer((req, res) => {
  res.writeHead(200, { 'Content-Type': 'text/plain' });
  fs.createReadStream('big-file.txt').pipe(res);
}).listen(3000);
```

### Using environment variables for the port

```js
const PORT = process.env.PORT || 3000;
const HOST = process.env.HOST || '127.0.0.1';

server.listen(PORT, HOST, () => {
  console.log(`Server running at http://${HOST}:${PORT}`);
});
```

### Error handling

```js
const server = http.createServer((req, res) => {
  try {
    // your logic
    res.end('OK');
  } catch (err) {
    res.writeHead(500, { 'Content-Type': 'text/plain' });
    res.end('Internal Server Error');
  }
});

server.on('error', (err) => {
  if (err.code === 'EADDRINUSE') {
    console.error('Port already in use!');
  } else {
    console.error(err);
  }
});
```

### Graceful shutdown

```js
process.on('SIGINT', () => {
  console.log('Shutting down...');
  server.close(() => {
    console.log('Server closed.');
    process.exit(0);
  });
});
```

## 4. Routing

**Routing** means deciding what the server does based on the **URL path** and the **HTTP method**. Without a framework, you do this manually.

### Basic routing with `if / else`

```js
const http = require('http');

const server = http.createServer((req, res) => {
  const { url, method } = req;

  if (url === '/' && method === 'GET') {
    res.writeHead(200, { 'Content-Type': 'text/html' });
    res.end('<h1>Home Page</h1>');
  } else if (url === '/about' && method === 'GET') {
    res.writeHead(200, { 'Content-Type': 'text/html' });
    res.end('<h1>About Page</h1>');
  } else if (url === '/contact' && method === 'GET') {
    res.writeHead(200, { 'Content-Type': 'text/html' });
    res.end('<h1>Contact Page</h1>');
  } else {
    res.writeHead(404, { 'Content-Type': 'text/html' });
    res.end('<h1>404 - Page Not Found</h1>');
  }
});

server.listen(3000, () => console.log('Running on port 3000'));
```

### Routing with `switch`

```js
const server = http.createServer((req, res) => {
  switch (req.url) {
    case '/':
      res.end('Home');
      break;
    case '/about':
      res.end('About');
      break;
    default:
      res.statusCode = 404;
      res.end('Not Found');
  }
});
```

### Parsing URLs and query strings

`req.url` includes the query string (`/search?q=node&page=2`). Parse it with the `URL` class.

```js
const http = require('http');

http.createServer((req, res) => {
  const baseURL = `http://${req.headers.host}`;
  const parsedUrl = new URL(req.url, baseURL);

  const pathname = parsedUrl.pathname;                 // '/search'
  const query = Object.fromEntries(parsedUrl.searchParams); // { q: 'node', page: '2' }

  res.writeHead(200, { 'Content-Type': 'application/json' });
  res.end(JSON.stringify({ pathname, query }));
}).listen(3000);
```

Test it:

```bash
curl "http://localhost:3000/search?q=node&page=2"
# {"pathname":"/search","query":{"q":"node","page":"2"}}
```

### Dynamic routes (URL parameters)

Example: `/users/42` where `42` is the user ID.

```js
const http = require('http');

const users = {
  1: { id: 1, name: 'Ali' },
  2: { id: 2, name: 'Sara' },
};

http.createServer((req, res) => {
  const { pathname } = new URL(req.url, `http://${req.headers.host}`);
  const match = pathname.match(/^\/users\/(\d+)$/);

  if (match && req.method === 'GET') {
    const id = match[1];
    const user = users[id];

    if (user) {
      res.writeHead(200, { 'Content-Type': 'application/json' });
      res.end(JSON.stringify(user));
    } else {
      res.writeHead(404, { 'Content-Type': 'application/json' });
      res.end(JSON.stringify({ error: 'User not found' }));
    }
  } else {
    res.writeHead(404);
    res.end('Not Found');
  }
}).listen(3000);
```

### Routing by HTTP method (REST-style API)

```js
const http = require('http');

let todos = [
  { id: 1, task: 'Learn Node.js', done: false },
];

const sendJSON = (res, status, data) => {
  res.writeHead(status, { 'Content-Type': 'application/json' });
  res.end(JSON.stringify(data));
};

const getBody = (req) =>
  new Promise((resolve, reject) => {
    let body = '';
    req.on('data', (chunk) => (body += chunk));
    req.on('end', () => {
      try {
        resolve(body ? JSON.parse(body) : {});
      } catch (err) {
        reject(err);
      }
    });
  });

const server = http.createServer(async (req, res) => {
  const { pathname } = new URL(req.url, `http://${req.headers.host}`);
  const method = req.method;

  // GET /todos -> list all
  if (pathname === '/todos' && method === 'GET') {
    return sendJSON(res, 200, todos);
  }

  // POST /todos -> create
  if (pathname === '/todos' && method === 'POST') {
    try {
      const body = await getBody(req);
      const newTodo = { id: Date.now(), task: body.task, done: false };
      todos.push(newTodo);
      return sendJSON(res, 201, newTodo);
    } catch {
      return sendJSON(res, 400, { error: 'Invalid JSON' });
    }
  }

  // GET /todos/:id -> single item
  const match = pathname.match(/^\/todos\/(\d+)$/);
  if (match) {
    const id = Number(match[1]);
    const todo = todos.find((t) => t.id === id);

    if (!todo) return sendJSON(res, 404, { error: 'Todo not found' });

    if (method === 'GET') return sendJSON(res, 200, todo);

    if (method === 'PUT') {
      const body = await getBody(req);
      Object.assign(todo, body);
      return sendJSON(res, 200, todo);
    }

    if (method === 'DELETE') {
      todos = todos.filter((t) => t.id !== id);
      res.writeHead(204);
      return res.end();
    }
  }

  // Fallback
  sendJSON(res, 404, { error: 'Route not found' });
});

server.listen(3000, () => console.log('API running on http://localhost:3000'));
```

Test with curl:

```bash
# List
curl http://localhost:3000/todos

# Create
curl -X POST -H "Content-Type: application/json" \
     -d '{"task":"Build API"}' http://localhost:3000/todos

# Update
curl -X PUT -H "Content-Type: application/json" \
     -d '{"done":true}' http://localhost:3000/todos/1

# Delete
curl -X DELETE http://localhost:3000/todos/1
```

### Building a simple router (cleaner approach)

Instead of long `if/else` chains, store routes in an object.

```js
const http = require('http');

const routes = {
  'GET /': (req, res) => res.end('Home'),
  'GET /about': (req, res) => res.end('About'),
  'POST /login': (req, res) => res.end('Logging in...'),
};

const server = http.createServer((req, res) => {
  const { pathname } = new URL(req.url, `http://${req.headers.host}`);
  const key = `${req.method} ${pathname}`;
  const handler = routes[key];

  if (handler) {
    handler(req, res);
  } else {
    res.statusCode = 404;
    res.end('404 Not Found');
  }
});

server.listen(3000);
```

### Serving static files

```js
const http = require('http');
const fs = require('fs');
const path = require('path');

const mimeTypes = {
  '.html': 'text/html',
  '.css': 'text/css',
  '.js': 'application/javascript',
  '.json': 'application/json',
  '.png': 'image/png',
  '.jpg': 'image/jpeg',
};

http.createServer((req, res) => {
  const { pathname } = new URL(req.url, `http://${req.headers.host}`);
  const safePath = path.normalize(pathname).replace(/^(\.\.[\/\\])+/, ''); // block ../ attacks
  let filePath = path.join(__dirname, 'public', safePath === '/' ? 'index.html' : safePath);

  const ext = path.extname(filePath);
  const contentType = mimeTypes[ext] || 'application/octet-stream';

  fs.readFile(filePath, (err, content) => {
    if (err) {
      res.writeHead(404, { 'Content-Type': 'text/plain' });
      return res.end('File not found');
    }
    res.writeHead(200, { 'Content-Type': contentType });
    res.end(content);
  });
}).listen(3000);
```

> **Security note:** always sanitize file paths to prevent **directory traversal** attacks (e.g. `/../../etc/passwd`).

### Redirects

```js
if (req.url === '/old-page') {
  res.writeHead(301, { Location: '/new-page' });
  return res.end();
}
```

### Limitations of manual routing

- Verbose and repetitive
- No built-in parameter parsing
- No middleware system
- Body parsing, CORS, and cookies must be handled by hand

This is why most real projects use **Express** (or Fastify). For comparison, the same routes in Express:

```js
const express = require('express');
const app = express();

app.use(express.json());

app.get('/', (req, res) => res.send('Home'));
app.get('/users/:id', (req, res) => res.json({ id: req.params.id }));
app.post('/todos', (req, res) => res.status(201).json(req.body));

app.listen(3000);
```

## 5. Putting It All Together

A complete small app with logging, routing, JSON handling, and error handling:

```js
// server.js
const http = require('http');

const PORT = process.env.PORT || 3000;

// ---------- Helpers ----------
const sendJSON = (res, status, data) => {
  res.writeHead(status, { 'Content-Type': 'application/json' });
  res.end(JSON.stringify(data));
};

const logger = (req) => {
  console.log(`[${new Date().toISOString()}] ${req.method} ${req.url}`);
};

// ---------- Route handlers ----------
const handlers = {
  home: (req, res) => {
    res.writeHead(200, { 'Content-Type': 'text/html' });
    res.end('<h1>Welcome to my Node server</h1>');
  },

  time: (req, res) => sendJSON(res, 200, { time: new Date().toISOString() }),

  greet: (req, res, url) => {
    const name = url.searchParams.get('name') || 'Guest';
    sendJSON(res, 200, { message: `Hello, ${name}!` });
  },

  echo: (req, res) => {
    let body = '';
    req.on('data', (c) => (body += c));
    req.on('end', () => {
      try {
        sendJSON(res, 200, { youSent: JSON.parse(body) });
      } catch {
        sendJSON(res, 400, { error: 'Invalid JSON' });
      }
    });
  },

  notFound: (req, res) => sendJSON(res, 404, { error: 'Route not found' }),
};

// ---------- Server ----------
const server = http.createServer((req, res) => {
  logger(req);
  const url = new URL(req.url, `http://${req.headers.host}`);
  const route = `${req.method} ${url.pathname}`;

  try {
    switch (route) {
      case 'GET /':        return handlers.home(req, res);
      case 'GET /time':    return handlers.time(req, res);
      case 'GET /greet':   return handlers.greet(req, res, url);
      case 'POST /echo':   return handlers.echo(req, res);
      default:             return handlers.notFound(req, res);
    }
  } catch (err) {
    console.error(err);
    sendJSON(res, 500, { error: 'Internal Server Error' });
  }
});

server.listen(PORT, () => console.log(`Server running on http://localhost:${PORT}`));
```

Try it:

```bash
curl http://localhost:3000/time
curl "http://localhost:3000/greet?name=Ali"
curl -X POST -H "Content-Type: application/json" -d '{"hi":"there"}' http://localhost:3000/echo
```

## 6. Quick Reference

### Cheat sheet

```js
// Create server
const server = http.createServer((req, res) => { ... });
server.listen(3000);

// Request info
req.method          // 'GET', 'POST', ...
req.url             // '/path?x=1'
req.headers         // { host: '...', ... }

// Parse URL
const url = new URL(req.url, `http://${req.headers.host}`);
url.pathname        // '/path'
url.searchParams    // URLSearchParams

// Read body
req.on('data', chunk => ...);
req.on('end', () => ...);

// Send response
res.writeHead(200, { 'Content-Type': 'application/json' });
res.end(JSON.stringify({ ok: true }));
```

### Common mistakes

|Mistake|Fix|
|---|---|
|Forgetting `res.end()`|Always end the response, or the request hangs|
|Calling `res.end()` twice|Use `return res.end()` to stop execution|
|Setting headers after `res.write()`|Headers must be set **before** sending body|
|Not handling 404|Add a default/fallback route|
|Parsing JSON without try/catch|Malformed JSON will crash the server|
|Ignoring `req.url` query string|Use `new URL()` to separate path and query|
|Trusting file paths from the URL|Sanitize to prevent directory traversal|

### Summary

- The **`http` module** is Node's built-in tool for web servers and clients.
- Each request goes through the cycle: **connection → request → handler → response → end**.
- `http.createServer()` plus `.listen()` gives you a working server.
- **Routing** is matching `req.method` and `req.url` to handlers. Do it manually for learning, then switch to **Express** for real projects.
