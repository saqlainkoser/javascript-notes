
## 1. Introduction to Express.js

### What is Express?

**Express.js** is a fast, minimal, and flexible **web framework for Node.js**. It is built on top of the core `http` module and removes most of the repetitive work (routing, body parsing, response helpers, middleware).

```bash
npm install express
```

### Why Express over the plain `http` module?

| Task         | Plain `http`                           | Express                     |
| ------------ | -------------------------------------- | --------------------------- |
| Routing      | Manual `if/else` on `req.url`          | `app.get('/path', handler)` |
| URL params   | Regex parsing                          | `req.params.id`             |
| Query string | `new URL()` parsing                    | `req.query`                 |
| JSON body    | Manual stream + `JSON.parse`           | `express.json()` middleware |
| Send JSON    | `writeHead` + `JSON.stringify` + `end` | `res.json(data)`            |
| Static files | Manual `fs` + MIME types               | `express.static()`          |
| Middleware   | None                                   | Built in                    |

### Same server, two ways

**Plain http**

```js
const http = require('http');

http.createServer((req, res) => {
  if (req.url === '/' && req.method === 'GET') {
    res.writeHead(200, { 'Content-Type': 'application/json' });
    res.end(JSON.stringify({ message: 'Hello' }));
  } else {
    res.writeHead(404);
    res.end('Not Found');
  }
}).listen(3000);
```

**Express**

```js
const express = require('express');
const app = express();

app.get('/', (req, res) => res.json({ message: 'Hello' }));

app.listen(3000);
```

### Key features

- Simple, readable routing
- Middleware system
- Template engine support (EJS, Pug)
- Static file serving
- Huge ecosystem (`cors`, `helmet`, `morgan`, `multer`...)
- Basis of many frameworks and the **E** in the **MERN** stack

## 2. Creating an Express Server

### Project setup

```bash
mkdir express-app && cd express-app
npm init -y
npm install express
npm install nodemon -D
```

`package.json` scripts:

```json
"scripts": {
  "start": "node index.js",
  "dev": "nodemon index.js"
}
```

### Minimal server

```js
// index.js
const express = require('express');

const app = express();          // 1. create the app
const PORT = 3000;

app.get('/', (req, res) => {    // 2. define a route
  res.send('Hello, Express!');
});

app.listen(PORT, () => {        // 3. start listening
  console.log(`Server running at http://localhost:${PORT}`);
});
```

Run it:

```bash
npm run dev
```

### ES Modules version

Add `"type": "module"` to `package.json`, then:

```js
import express from 'express';

const app = express();

app.get('/', (req, res) => res.send('Hello, Express!'));

app.listen(3000, () => console.log('Server running on port 3000'));
```

### Using environment variables

```js
require('dotenv').config();
const express = require('express');

const app = express();
const PORT = process.env.PORT || 3000;

app.listen(PORT, () => console.log(`Running on port ${PORT}`));
```

### Basic middleware setup

Most apps start with these two lines:

```js

```

## 3. Routing

**Routing** decides how the app responds to a request based on the **HTTP method** and the **URL path**.

### Route syntax

```js
app.METHOD(PATH, HANDLER);
```

|Part|Meaning|
|---|---|
|`app`|The Express instance|
|`METHOD`|`get`, `post`, `put`, `patch`, `delete`|
|`PATH`|URL path on the server|
|`HANDLER`|Function `(req, res)` that runs on a match|

### HTTP methods

```js
app.get('/users', (req, res) => res.send('Get all users'));
app.post('/users', (req, res) => res.send('Create a user'));
app.put('/users/:id', (req, res) => res.send('Replace a user'));
app.patch('/users/:id', (req, res) => res.send('Update part of a user'));
app.delete('/users/:id', (req, res) => res.send('Delete a user'));
```

|Method|Purpose|CRUD|
|---|---|---|
|`GET`|Read data|Read|
|`POST`|Create data|Create|
|`PUT`|Replace data entirely|Update|
|`PATCH`|Update part of data|Update|
|`DELETE`|Remove data|Delete|

### Route parameters (`req.params`)

```js
app.get('/users/:id', (req, res) => {
  res.send(`User ID: ${req.params.id}`);
});
// GET /users/42  ->  "User ID: 42"
```

Multiple parameters:

```js
app.get('/users/:userId/posts/:postId', (req, res) => {
  const { userId, postId } = req.params;
  res.json({ userId, postId });
});
// GET /users/5/posts/12  ->  { "userId": "5", "postId": "12" }
```

> Parameters are always **strings**. Convert with `Number(req.params.id)` when needed.

### Query strings (`req.query`)

```js
app.get('/search', (req, res) => {
  const { q, page = 1 } = req.query;
  res.json({ q, page });
});
// GET /search?q=node&page=2  ->  { "q": "node", "page": "2" }
```

### Route handling all methods

```js
app.all('/secret', (req, res) => {
  res.send(`Method used: ${req.method}`);
});
```

### Wildcard / 404 route

Place this **last**, after all other routes:

```js
app.use((req, res) => {
  res.status(404).json({ error: 'Route not found' });
});
```

### Multiple handlers on one route

```js
const checkAuth = (req, res, next) => {
  console.log('Checking auth...');
  next();                        // pass control to the next function
};

app.get('/dashboard', checkAuth, (req, res) => {
  res.send('Dashboard');
});
```

### Chaining routes with `app.route()`

```js
app.route('/books')
  .get((req, res) => res.send('Get all books'))
  .post((req, res) => res.send('Add a book'));
```

### `express.Router()` (modular routing)

Split routes into separate files so `index.js` stays clean.

**routes/userRoutes.js**

```js
const express = require('express');
const router = express.Router();

router.get('/', (req, res) => res.send('All users'));

router.get('/:id', (req, res) => res.send(`User ${req.params.id}`));

router.post('/', (req, res) => res.status(201).send('User created'));

router.delete('/:id', (req, res) => res.send(`User ${req.params.id} deleted`));

module.exports = router;
```

**index.js**

```js
const express = require('express');
const userRoutes = require('./routes/userRoutes');

const app = express();
app.use(express.json());

app.use('/api/users', userRoutes);   // all routes get this prefix

app.listen(3000);
```

Resulting endpoints:

|Request|Handled by|
|---|---|
|`GET /api/users`|`router.get('/')`|
|`GET /api/users/5`|`router.get('/:id')`|
|`POST /api/users`|`router.post('/')`|
|`DELETE /api/users/5`|`router.delete('/:id')`|

### Route order matters

Express checks routes **top to bottom** and uses the first match.

```js
app.get('/users/new', (req, res) => res.send('New user form'));   // specific first
app.get('/users/:id', (req, res) => res.send('User by id'));      // dynamic after
```

If you reverse them, `/users/new` would be treated as `:id = "new"`.

## 4. Request Object (req)

`req` represents the incoming HTTP request. Express extends Node's `IncomingMessage` with extra helpers.

### Common properties

|Property|Description|Example|
|---|---|---|
|`req.params`|Route parameters|`/users/:id` -> `{ id: '5' }`|
|`req.query`|Query string values|`?page=2` -> `{ page: '2' }`|
|`req.body`|Parsed request body (needs middleware)|`{ name: 'Ali' }`|
|`req.headers`|All headers (lowercase keys)|`req.headers['user-agent']`|
|`req.method`|HTTP method|`'POST'`|
|`req.url`|URL as received (relative to router)|`'/users?id=5'`|
|`req.originalUrl`|Full original URL|`'/api/users?id=5'`|
|`req.path`|Path only, no query|`'/users'`|
|`req.hostname`|Host name|`'localhost'`|
|`req.ip`|Client IP address|`'::1'`|
|`req.protocol`|`http` or `https`|`'http'`|
|`req.cookies`|Cookies (needs `cookie-parser`)|`{ token: 'abc' }`|
|`req.files` / `req.file`|Uploaded files (needs `multer`)||

### Useful methods

```js
req.get('Content-Type');       // read a header (case-insensitive)
req.is('json');                // check content type -> true/false
req.accepts('json');           // check what client accepts
```

### Example: inspecting a request

```js
app.get('/inspect/:id', (req, res) => {
  res.json({
    method: req.method,
    path: req.path,
    originalUrl: req.originalUrl,
    params: req.params,
    query: req.query,
    userAgent: req.get('User-Agent'),
    ip: req.ip,
  });
});
```

```bash
curl "http://localhost:3000/inspect/7?color=red"
```

### Reading the body (`req.body`)

`req.body` is `undefined` unless you add a body-parsing middleware.

```js
app.use(express.json());                           // for JSON
app.use(express.urlencoded({ extended: true }));   // for HTML form data

app.post('/users', (req, res) => {
  const { name, email } = req.body;
  res.status(201).json({ message: 'User created', name, email });
});
```

```bash
curl -X POST http://localhost:3000/users \
  -H "Content-Type: application/json" \
  -d '{"name":"Ali","email":"ali@example.com"}'
```

### Where does data come from?

|Source|Access|Typical use|
|---|---|---|
|URL path|`req.params`|Identify a resource (`/users/5`)|
|Query string|`req.query`|Filter, sort, paginate, search|
|Body|`req.body`|Create or update data (POST/PUT/PATCH)|
|Headers|`req.headers`|Auth tokens, content type|
|Cookies|`req.cookies`|Sessions, tokens|

## 5. Response Object (res)

`res` is used to send data back to the client. Always finish the request with **one** response method.

### Common methods

|Method|Description|
|---|---|
|`res.send(data)`|Send text, HTML, object, or buffer|
|`res.json(obj)`|Send JSON (sets `Content-Type` automatically)|
|`res.status(code)`|Set the status code (chainable)|
|`res.sendStatus(code)`|Set the status and send its text|
|`res.redirect(url)`|Redirect the client|
|`res.sendFile(path)`|Send a file|
|`res.download(path)`|Prompt a file download|
|`res.render(view)`|Render a template (EJS, Pug)|
|`res.set(name, value)`|Set a header|
|`res.cookie(name, value)`|Set a cookie|
|`res.clearCookie(name)`|Remove a cookie|
|`res.end()`|End without data|

### Examples

**Send text or HTML**

```js
app.get('/', (req, res) => {
  res.send('Hello');
});

app.get('/html', (req, res) => {
  res.send('<h1>Welcome</h1><p>This is HTML</p>');
});
```

**Send JSON**

```js
app.get('/api/user', (req, res) => {
  res.json({ id: 1, name: 'Ali', skills: ['JS', 'Node'] });
});
```

**Set a status code**

```js
app.post('/users', (req, res) => {
  res.status(201).json({ message: 'Created' });
});

app.get('/missing', (req, res) => {
  res.status(404).json({ error: 'Not found' });
});
```

**Shortcut status**

```js
res.sendStatus(204);   // sends "No Content"
res.sendStatus(404);   // sends "Not Found"
```

**Redirect**

```js
app.get('/old', (req, res) => {
  res.redirect('/new');                // 302 by default
});

app.get('/moved', (req, res) => {
  res.redirect(301, '/permanent');     // permanent redirect
});
```

**Send a file**

```js
const path = require('path');

app.get('/page', (req, res) => {
  res.sendFile(path.join(__dirname, 'public', 'index.html'));
});

app.get('/download', (req, res) => {
  res.download(path.join(__dirname, 'files', 'report.pdf'));
});
```

**Set headers**

```js
res.set('X-Powered-By-Me', 'Express');
res.set({
  'Cache-Control': 'no-store',
  'X-Custom': 'value',
});
```

**Set a cookie**

```js
res.cookie('token', 'abc123', {
  httpOnly: true,
  maxAge: 24 * 60 * 60 * 1000,   // 1 day
});
```

### Common status codes

|Code|Meaning|Use|
|---|---|---|
|`200`|OK|Successful GET/PUT/PATCH|
|`201`|Created|Successful POST|
|`204`|No Content|Successful DELETE|
|`400`|Bad Request|Invalid input|
|`401`|Unauthorized|Not logged in|
|`403`|Forbidden|No permission|
|`404`|Not Found|Resource or route missing|
|`409`|Conflict|Duplicate (e.g. email exists)|
|`500`|Internal Server Error|Server bug|

### Important rules

```js
// WRONG: sends two responses -> "Cannot set headers after they are sent"
app.get('/bad', (req, res) => {
  res.send('First');
  res.send('Second');
});

// RIGHT: return after responding
app.get('/good', (req, res) => {
  if (!req.query.name) {
    return res.status(400).send('Name required');
  }
  res.send(`Hello ${req.query.name}`);
});
```

- Send **only one** response per request.
- Use `return` before `res.send()` in early exits.
- Set status **before** sending: `res.status(404).send(...)`.

### Serving static files

```js
app.use(express.static('public'));
```

A file at `public/style.css` is now available at `http://localhost:3000/style.css`.

With a URL prefix:

```js
app.use('/assets', express.static('public'));
// public/style.css -> /assets/style.css
```

## 6. Putting It All Together

A small in-memory **Users API** that uses routing, `req`, and `res`.

### Structure

```
users-api/
├── .env
├── package.json
└── index.js
```

### `.env`

```env
PORT=3000
```

### `index.js`

```js
require('dotenv').config();
const express = require('express');

const app = express();
const PORT = process.env.PORT || 3000;

// ---------- Middleware ----------
app.use(express.json());

app.use((req, res, next) => {                 // simple logger
  console.log(`${req.method} ${req.originalUrl}`);
  next();
});

// ---------- Fake database ----------
let users = [
  { id: 1, name: 'Ali', email: 'ali@example.com' },
  { id: 2, name: 'Sara', email: 'sara@example.com' },
];

// ---------- Routes ----------

// Home
app.get('/', (req, res) => {
  res.send('<h1>Users API</h1><p>Try GET /api/users</p>');
});

// GET all users (supports ?name=ali search)
app.get('/api/users', (req, res) => {
  const { name } = req.query;

  if (name) {
    const filtered = users.filter((u) =>
      u.name.toLowerCase().includes(name.toLowerCase())
    );
    return res.json(filtered);
  }

  res.json(users);
});

// GET one user
app.get('/api/users/:id', (req, res) => {
  const user = users.find((u) => u.id === Number(req.params.id));

  if (!user) {
    return res.status(404).json({ error: 'User not found' });
  }

  res.json(user);
});

// POST create user
app.post('/api/users', (req, res) => {
  const { name, email } = req.body;

  if (!name || !email) {
    return res.status(400).json({ error: 'Name and email are required' });
  }

  const newUser = { id: Date.now(), name, email };
  users.push(newUser);

  res.status(201).json(newUser);
});

// PUT update user
app.put('/api/users/:id', (req, res) => {
  const user = users.find((u) => u.id === Number(req.params.id));

  if (!user) {
    return res.status(404).json({ error: 'User not found' });
  }

  const { name, email } = req.body;
  if (name) user.name = name;
  if (email) user.email = email;

  res.json(user);
});

// DELETE user
app.delete('/api/users/:id', (req, res) => {
  const id = Number(req.params.id);
  const exists = users.some((u) => u.id === id);

  if (!exists) {
    return res.status(404).json({ error: 'User not found' });
  }

  users = users.filter((u) => u.id !== id);
  res.sendStatus(204);
});

// ---------- 404 handler (must be last) ----------
app.use((req, res) => {
  res.status(404).json({ error: `Cannot ${req.method} ${req.originalUrl}` });
});

// ---------- Start ----------
app.listen(PORT, () => {
  console.log(`Server running at http://localhost:${PORT}`);
});
```

### Test with curl

```bash

# Search

# One user

```

## 7. Quick Reference

### Cheat sheet

```js
const express = require('express');
const app = express();

// Middleware
app.use(express.json());
app.use(express.urlencoded({ extended: true }));
app.use(express.static('public'));

// Routes
app.get('/path', (req, res) => { ... });
app.post('/path', (req, res) => { ... });
app.put('/path/:id', (req, res) => { ... });
app.delete('/path/:id', (req, res) => { ... });

// Request data
req.params.id        // /users/:id
req.query.page       // ?page=2
req.body.name        // JSON/form body
req.headers.authorization
req.get('Content-Type')

// Responses
res.send('text');
res.json({ ok: true });
res.status(201).json({ created: true });
res.sendStatus(204);
res.redirect('/home');
res.sendFile(absolutePath);

// Start
app.listen(3000, () => console.log('Running'));
```

### Plain `http` vs Express

|Feature|`http`|Express|
|---|---|---|
|Learning curve|Low-level|Beginner-friendly|
|Routing|Manual|Built in|
|Middleware|No|Yes|
|Body parsing|Manual|`express.json()`|
|JSON response|`JSON.stringify` + headers|`res.json()`|
|Code size|Large|Small|

### Common mistakes

|Mistake|Fix|
|---|---|
|`req.body` is `undefined`|Add `app.use(express.json())` **before** routes|
|"Cannot set headers after they are sent"|Send only one response; use `return`|
|Request hangs forever|Always call `res.send()`, `res.json()`, or `res.end()`|
|Dynamic route catching specific one|Put specific routes **before** `/:id` routes|
|404 handler placed first|Put it **last**|
|Comparing `req.params.id` to a number|Convert: `Number(req.params.id)`|
|Forgetting `next()` in middleware|Call `next()` or the request stalls|
|Hardcoding the port|Use `process.env.PORT \| 3000`|
|Using `res.send()` with status in wrong order|Use `res.status(404).send(...)`|

### Summary

- **Express** is a minimal framework on top of Node's `http` module that simplifies servers and APIs.
- Create a server with `express()`, define routes, and call `app.listen()`.
- **Routing** maps a method and path to a handler; use `req.params`, `req.query`, and `req.body` to read input, and `express.Router()` to organize routes.
- **`req`** carries everything the client sent; **`res`** sends the reply (`send`, `json`, `status`, `redirect`, `sendFile`).
