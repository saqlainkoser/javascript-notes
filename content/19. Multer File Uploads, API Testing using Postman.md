
## 1. How File Uploads Work

### The problem

`express.json()` and `express.urlencoded()` cannot read files. Files are sent as **`multipart/form-data`**, a format that splits the request into parts (text fields + binary files).

```
POST /upload HTTP/1.1
Content-Type: multipart/form-data; boundary=----abc123

------abc123
Content-Disposition: form-data; name="username"

ali
------abc123
Content-Disposition: form-data; name="avatar"; filename="me.png"
Content-Type: image/png

<binary data>
------abc123--
```

### The solution

**Multer** is middleware that parses `multipart/form-data`, saves files, and fills:

|Property|Contains|
|---|---|
|`req.file`|A single uploaded file|
|`req.files`|Multiple uploaded files|
|`req.body`|The text fields sent with the form|

### Content-Type cheat sheet

|Content-Type|Parser|
|---|---|
|`application/json`|`express.json()`|
|`application/x-www-form-urlencoded`|`express.urlencoded()`|
|`multipart/form-data`|**Multer**|

## 2. Multer

### Install

```bash
npm install multer
```

### Quick start

```js
const express = require('express');
const multer = require('multer');

const app = express();
const upload = multer({ dest: 'uploads/' });   // saves files to ./uploads

app.post('/upload', upload.single('avatar'), (req, res) => {
  console.log(req.file);    // file info
  console.log(req.body);    // text fields
  res.json({ message: 'Uploaded!', file: req.file });
});

app.listen(3000);
```

> The string in `upload.single('avatar')` must **exactly match** the field name sent by the client.

### What `req.file` looks like

```js
{
  fieldname: 'avatar',
  originalname: 'me.png',
  encoding: '7bit',
  mimetype: 'image/png',
  destination: 'uploads/',
  filename: 'b1c2d3e4f5...',     // random name, no extension
  path: 'uploads/b1c2d3e4f5...',
  size: 24680                    // bytes
}
```

### Upload methods

|Method|Use|Result in|
|---|---|---|
|`upload.single('field')`|One file|`req.file`|
|`upload.array('field', maxCount)`|Many files, same field|`req.files` (array)|
|`upload.fields([{ name, maxCount }, ...])`|Many files, different fields|`req.files` (object)|
|`upload.none()`|Text fields only (multipart form)|`req.body`|
|`upload.any()`|Any files (avoid; less safe)|`req.files`|

### Storage engines

**1. DiskStorage**: save files on the server's disk with full control.

```js
const path = require('path');
const multer = require('multer');

const storage = multer.diskStorage({
  destination: (req, file, cb) => {
    cb(null, 'uploads/');                          // folder must exist
  },
  filename: (req, file, cb) => {
    const unique = Date.now() + '-' + Math.round(Math.random() * 1e9);
    const ext = path.extname(file.originalname);   // .png
    cb(null, `${file.fieldname}-${unique}${ext}`); // avatar-1700000000-123456.png
  },
});

const upload = multer({ storage });
```

The `cb(error, value)` callback: pass `null` as the first argument when there is no error.

**2. MemoryStorage**: keep the file in RAM as a `Buffer` (`req.file.buffer`). Useful when forwarding to cloud storage (Cloudinary, S3). Avoid for large files.

```js
const upload = multer({ storage: multer.memoryStorage() });

app.post('/upload', upload.single('file'), (req, res) => {
  console.log(req.file.buffer);   // <Buffer ...>
});
```

||DiskStorage|MemoryStorage|
|---|---|---|
|Saved to|Server disk|RAM (`buffer`)|
|Good for|Local uploads|Passing on to cloud services|
|Risk|Disk fills up|Memory fills up|

### Create the upload folder automatically

```js
const fs = require('fs');

const uploadDir = 'uploads';
if (!fs.existsSync(uploadDir)) {
  fs.mkdirSync(uploadDir, { recursive: true });
}
```

### Options


## 3. Upload Examples

### Single file

```js
app.post('/api/profile-picture', upload.single('avatar'), (req, res) => {
  if (!req.file) {
    return res.status(400).json({ success: false, message: 'No file uploaded' });
  }

  res.status(201).json({
    success: true,
    message: 'Profile picture uploaded',
    file: {
      name: req.file.filename,
      size: req.file.size,
      url: `/uploads/${req.file.filename}`,
    },
  });
});
```

### Multiple files (same field)

```js
app.post('/api/gallery', upload.array('photos', 5), (req, res) => {
  if (!req.files || req.files.length === 0) {
    return res.status(400).json({ success: false, message: 'No files uploaded' });
  }

  const files = req.files.map((f) => ({
    name: f.filename,
    url: `/uploads/${f.filename}`,
  }));

  res.status(201).json({ success: true, count: files.length, files });
});
```

### Multiple fields

```js
const cpUpload = upload.fields([
  { name: 'avatar', maxCount: 1 },
  { name: 'documents', maxCount: 3 },
]);

app.post('/api/register', cpUpload, (req, res) => {
  const avatar = req.files['avatar']?.[0];
  const documents = req.files['documents'] || [];

  res.json({
    body: req.body,                  // text fields
    avatar: avatar?.filename,
    documents: documents.map((d) => d.filename),
  });
});
```

### File + text fields together

```js
app.post('/api/products', upload.single('image'), (req, res) => {
  const { name, price } = req.body;     // text fields (strings!)

  const product = {
    name,
    price: Number(price),
    image: req.file ? `/uploads/${req.file.filename}` : null,
  };

  res.status(201).json({ success: true, data: product });
});
```

> **Order matters:** Multer must run **before** you read `req.body` for a multipart request. Fields are only available after Multer has parsed the form.

### Deleting a file from disk

```js
const fs = require('fs/promises');
const path = require('path');

const removeFile = async (filename) => {
  try {
    await fs.unlink(path.join(__dirname, 'uploads', filename));
  } catch (err) {
    if (err.code !== 'ENOENT') throw err;   // ignore "file doesn't exist"
  }
};
```

## 4. Serving, Validating and Securing Uploads

### Serving uploaded files

```js
const path = require('path');

app.use('/uploads', express.static(path.join(__dirname, 'uploads')));
```

A file saved as `uploads/avatar-123.png` is now available at `http://localhost:3000/uploads/avatar-123.png`.

### Filtering file types

```js
const fileFilter = (req, file, cb) => {
  const allowed = ['image/jpeg', 'image/png', 'image/webp'];

  if (allowed.includes(file.mimetype)) {
    cb(null, true);                                            // accept
  } else {
    cb(new Error('Only JPEG, PNG and WEBP images are allowed')); // reject
  }
};

const upload = multer({
  storage,
  fileFilter,
  limits: { fileSize: 2 * 1024 * 1024 },
});
```

Common MIME types:

|File|MIME type|
|---|---|
|JPEG|`image/jpeg`|
|PNG|`image/png`|
|WEBP|`image/webp`|
|PDF|`application/pdf`|
|CSV|`text/csv`|
|Word (.docx)|`application/vnd.openxmlformats-officedocument.wordprocessingml.document`|

> `file.mimetype` comes from the client and can be faked. For high-security apps, also inspect the file's real content (for example with the `file-type` package).

### Handling Multer errors

Multer throws `MulterError` for limit violations. Handle them in your error middleware.

```js
const multer = require('multer');

app.use((err, req, res, next) => {
  if (err instanceof multer.MulterError) {
    const messages = {
      LIMIT_FILE_SIZE: 'File is too large (max 2 MB)',
      LIMIT_FILE_COUNT: 'Too many files uploaded',
      LIMIT_UNEXPECTED_FILE: `Unexpected field: ${err.field}`,
    };

    return res.status(400).json({
      success: false,
      message: messages[err.code] || err.message,
    });
  }

  // errors thrown by fileFilter
  if (err.message?.startsWith('Only')) {
    return res.status(400).json({ success: false, message: err.message });
  }

  next(err);
});
```

|Error code|Cause|
|---|---|
|`LIMIT_FILE_SIZE`|File bigger than `limits.fileSize`|
|`LIMIT_FILE_COUNT`|More files than `limits.files`|
|`LIMIT_UNEXPECTED_FILE`|Field name doesn't match (`upload.single('x')` vs the sent field)|

### Security checklist

|Do|Why|
|---|---|
|Set `limits.fileSize`|Prevents huge uploads and DoS|
|Use `fileFilter`|Only accept expected types|
|Generate your own filenames|Never trust `originalname` (path tricks like `../../x.js`)|
|Store uploads outside the source folder or on cloud storage|Keeps code and user data separate|
|Require auth (`protect`) on upload routes|Stops anonymous abuse|
|Never serve uploads as executable code|Prevents script uploads running|
|Add `uploads/` to `.gitignore`|Don't commit user files|

```
# .gitignore
node_modules/
.env
uploads/*
!uploads/.gitkeep
```

### Cloud storage (concept)

On hosts with temporary disks (Render, Heroku, Vercel), files saved locally **disappear on restart**. In production, upload to cloud storage and save only the URL in your database:

- **Cloudinary**: images and video, easy for beginners
- **AWS S3**: general-purpose object storage
- **Firebase Storage**, **Supabase Storage**

Pattern with Cloudinary and memory storage:

```js
const cloudinary = require('cloudinary').v2;
const streamifier = require('streamifier');

cloudinary.config({
  cloud_name: process.env.CLOUD_NAME,
  api_key: process.env.CLOUD_API_KEY,
  api_secret: process.env.CLOUD_API_SECRET,
});

const uploadToCloud = (buffer) =>
  new Promise((resolve, reject) => {
    const stream = cloudinary.uploader.upload_stream(
      { folder: 'my-app' },
      (error, result) => (error ? reject(error) : resolve(result))
    );
    streamifier.createReadStream(buffer).pipe(stream);
  });

app.post('/api/upload', upload.single('image'), async (req, res, next) => {
  try {
    const result = await uploadToCloud(req.file.buffer);
    res.status(201).json({ success: true, url: result.secure_url });
  } catch (err) {
    next(err);
  }
});
```

## 5. Uploading from the Frontend

### Plain HTML form

```html
<form action="http://localhost:3000/api/profile-picture"
      method="POST"
      enctype="multipart/form-data">
  <input type="text" name="username" />
  <input type="file" name="avatar" />
  <button type="submit">Upload</button>
</form>
```

> `enctype="multipart/form-data"` is required, otherwise no file is sent.

### JavaScript with `fetch` and `FormData`

```js
const input = document.querySelector('#fileInput');

const formData = new FormData();
formData.append('avatar', input.files[0]);   // field name must match Multer
formData.append('username', 'ali');

const res = await fetch('http://localhost:3000/api/profile-picture', {
  method: 'POST',
  body: formData,
  // DO NOT set Content-Type manually; the browser adds the boundary itself
});

const data = await res.json();
console.log(data);
```

### Axios (preview for the React notes)

```js
const formData = new FormData();
formData.append('avatar', file);

const { data } = await axios.post('/api/profile-picture', formData, {
  headers: { Authorization: `Bearer ${token}` },
});
```

### React sketch

```jsx
function AvatarUpload() {
  const [file, setFile] = useState(null);

  const handleSubmit = async (e) => {
    e.preventDefault();
    const formData = new FormData();
    formData.append('avatar', file);
    await axios.post('/api/profile-picture', formData);
  };

  return (
    <form onSubmit={handleSubmit}>
      <input type="file" accept="image/*" onChange={(e) => setFile(e.target.files[0])} />
      <button type="submit" disabled={!file}>Upload</button>
    </form>
  );
}
```

## 6. API Testing using Postman

### What is Postman?

**Postman** is a tool for building, sending, and testing HTTP requests **without writing a frontend**. You can test every endpoint of your Express API, inspect responses, save requests, and automate tests.

Download: https://www.postman.com/downloads (or use the web version).

Alternatives: **Thunder Client** (VS Code extension), **Insomnia**, **REST Client** (VS Code), `curl`.

### Postman interface

|Area|Purpose|
|---|---|
|**Method + URL bar**|Choose `GET`, `POST`... and enter the URL|
|**Params**|Query string key-values (`?page=2`)|
|**Authorization**|Bearer token, Basic auth, API key|
|**Headers**|Custom request headers|
|**Body**|Data sent (JSON, form-data...)|
|**Scripts (Pre-request / Post-response / Tests)**|JavaScript that runs before/after the request|
|**Response panel**|Body, headers, cookies, status code, time, size|
|**Collections**|Folders of saved requests|
|**Environments**|Sets of variables (`{{baseUrl}}`, `{{token}}`)|

### Sending your first request

1. Start your server: `npm run dev`
2. In Postman click **New > HTTP Request**
3. Select `GET`, enter `http://localhost:3000/api/products`
4. Click **Send**
5. Check status (`200 OK`), time, and JSON body

### Testing each request type

**GET with query params**

- Method: `GET`
- URL: `http://localhost:3000/api/products`
- **Params** tab: `category = electronics`, `sort = -price`
- Postman builds `?category=electronics&sort=-price`

**GET with a route parameter**

- URL: `http://localhost:3000/api/products/1`

**POST with JSON**

1. Method `POST`, URL `http://localhost:3000/api/products`
2. **Body** tab > select **raw** > choose **JSON** in the dropdown
3. Enter:

```json
{
  "name": "Keyboard",
  "price": 1500,
  "category": "electronics"
}
```

4. Send. Expect `201 Created`.

> Selecting **JSON** automatically sets `Content-Type: application/json`. Forgetting this is the most common reason `req.body` is `undefined`.

**PUT / PATCH**

- Same as POST, with method `PUT` or `PATCH` and URL `/api/products/1`

**DELETE**

- Method `DELETE`, URL `/api/products/1`. Expect `204 No Content`.

### Body types

|Body option|Use for|Express side|
|---|---|---|
|**raw > JSON**|API requests (most common)|`express.json()`|
|**x-www-form-urlencoded**|Simulating HTML forms|`express.urlencoded()`|
|**form-data**|File uploads + fields|**Multer**|
|**binary**|Raw file as body|Custom handling|
|**none**|GET/DELETE without a body||

### Testing file uploads (Multer)

1. Method `POST`, URL `http://localhost:3000/api/profile-picture`
2. **Body** tab > select **form-data**
3. In the key column, type `avatar`; hover the key field and change the type dropdown from **Text** to **File**
4. In the value column click **Select Files** and choose an image
5. Add text fields as extra rows (type **Text**): `username = ali`
6. Click **Send**

```
KEY         TYPE    VALUE
avatar      File    me.png
username    Text    ali
```

> The key (`avatar`) must match `upload.single('avatar')`. A mismatch gives `LIMIT_UNEXPECTED_FILE`. Do **not** manually set a `Content-Type` header for form-data. Postman adds the boundary automatically.

For multiple files, add several rows with the **same key** (`photos`) and use `upload.array('photos')`.

### Testing authentication (JWT)

**Step 1: Login**

- `POST /api/auth/login` with JSON `{ "email": "...", "password": "..." }`
- Copy the `token` from the response.

**Step 2: Send the token**

- Open a protected request (`GET /api/auth/me`)
- **Authorization** tab > Type **Bearer Token** > paste the token

This adds the header:

```
Authorization: Bearer eyJhbGciOiJIUzI1NiJ9...
```

Or add it manually in **Headers**: key `Authorization`, value `Bearer <token>`.

### Environments and variables

Avoid retyping URLs and tokens.

1. Click **Environments > Create** (for example "Local")
2. Add variables:

|Variable|Initial value|
|---|---|
|`baseUrl`|`http://localhost:3000`|
|`token`|_(empty for now)_|

3. Select the environment in the top-right dropdown
4. Use variables in requests with double curly braces:

```
URL:            {{baseUrl}}/api/products
Authorization:  Bearer {{token}}
```

Create a second environment ("Production") with `baseUrl = https://my-api.onrender.com`, then switch with one click.

### Automatically saving the token after login

In the **Login** request open the **Scripts > Post-response** tab (called **Tests** in older versions) and add:

```js
const data = pm.response.json();
pm.environment.set('token', data.token);
```

Now every request using `{{token}}` is authenticated automatically after you log in.

### Writing tests (assertions)

In the **Scripts > Post-response / Tests** tab:

```js
pm.test('Status is 201 Created', () => {
  pm.response.to.have.status(201);
});

pm.test('Response time is under 500ms', () => {
  pm.expect(pm.response.responseTime).to.be.below(500);
});

pm.test('Response has success and data', () => {
  const json = pm.response.json();
  pm.expect(json.success).to.be.true;
  pm.expect(json.data).to.have.property('id');
  pm.expect(json.data.name).to.eql('Keyboard');
});

pm.test('Content-Type is JSON', () => {
  pm.response.to.have.header('Content-Type', /application\/json/);
});
```

Results appear in the **Test Results** tab (green = pass, red = fail).

Test the failure paths too:

```js
pm.test('Returns 400 for invalid data', () => {
  pm.response.to.have.status(400);
  pm.expect(pm.response.json().success).to.be.false;
});
```

### Collections

A **collection** is a folder of saved requests, organised per project.

```
My API
├── Auth
│   ├── Register          POST {{baseUrl}}/api/auth/register
│   ├── Login             POST {{baseUrl}}/api/auth/login
│   └── Get Me            GET  {{baseUrl}}/api/auth/me
└── Products
    ├── Get All           GET    {{baseUrl}}/api/products
    ├── Get One           GET    {{baseUrl}}/api/products/:id
    ├── Create            POST   {{baseUrl}}/api/products
    ├── Update            PATCH  {{baseUrl}}/api/products/:id
    └── Delete            DELETE {{baseUrl}}/api/products/:id
```

Tips:

- Set **Authorization** once on the collection or folder (type Bearer, `{{token}}`) and let requests **inherit** it.
- **Save** with `Ctrl + S`.
- **Export** the collection as JSON to share it with teammates or commit it to Git.
- Use the **Collection Runner** to run every request in order and see which tests pass.

### Postman checklist for every endpoint

|Test case|Expected|
|---|---|
|Valid request|`200` / `201` + correct data|
|Missing required field|`400` + clear message|
|Wrong data type|`400`|
|Non-existent ID|`404`|
|Invalid ID format|`400`|
|No token on a protected route|`401`|
|Expired / invalid token|`401`|
|Wrong role (user calling admin route)|`403`|
|Duplicate unique value|`409`|
|File too large / wrong file type|`400`|

### Common Postman problems

|Problem|Cause and fix|
|---|---|
|`req.body` is `undefined`|Body not set to **raw > JSON**, or `express.json()` missing|
|`Cannot POST /api/x`|Wrong URL/method, or the route isn't registered|
|`ECONNREFUSED`|Server isn't running or the port is wrong|
|`401 Unauthorized`|Missing/expired token: log in again|
|`LIMIT_UNEXPECTED_FILE`|Form-data key doesn't match `upload.single('...')`|
|`req.file` is `undefined`|Key type left as **Text** instead of **File**|
|Invalid JSON error|Trailing comma or single quotes in the body|

## 7. Putting It All Together

### Goal

A protected **profile-picture upload API**: only logged-in users can upload; only images up to 2 MB are accepted; files are served statically and tested in Postman.

### Structure

```
upload-api/
├── .env
├── .gitignore
├── package.json
├── index.js
├── uploads/
├── middleware/
│   ├── auth.js           (from note 18)
│   └── upload.js
└── routes/
    └── uploadRoutes.js
```

### `middleware/upload.js`

```js
const multer = require('multer');
const path = require('path');
const fs = require('fs');

const uploadDir = path.join(__dirname, '..', 'uploads');
if (!fs.existsSync(uploadDir)) fs.mkdirSync(uploadDir, { recursive: true });

const storage = multer.diskStorage({
  destination: (req, file, cb) => cb(null, uploadDir),
  filename: (req, file, cb) => {
    const unique = `${Date.now()}-${Math.round(Math.random() * 1e9)}`;
    cb(null, `${file.fieldname}-${unique}${path.extname(file.originalname).toLowerCase()}`);
  },
});

const fileFilter = (req, file, cb) => {
  const allowed = ['image/jpeg', 'image/png', 'image/webp'];
  if (allowed.includes(file.mimetype)) return cb(null, true);
  cb(new Error('Only JPEG, PNG and WEBP images are allowed'));
};

module.exports = multer({
  storage,
  fileFilter,
  limits: { fileSize: 2 * 1024 * 1024, files: 5 },
});
```

### `routes/uploadRoutes.js`

```js
const express = require('express');
const upload = require('../middleware/upload');
const { protect } = require('../middleware/auth');

const router = express.Router();

// single image
router.post('/avatar', protect, upload.single('avatar'), (req, res) => {
  if (!req.file) {
    return res.status(400).json({ success: false, message: 'Please attach an image' });
  }

  res.status(201).json({
    success: true,
    message: 'Avatar uploaded',
    data: {
      filename: req.file.filename,
      size: req.file.size,
      url: `${req.protocol}://${req.get('host')}/uploads/${req.file.filename}`,
    },
  });
});

// multiple images
router.post('/gallery', protect, upload.array('photos', 5), (req, res) => {
  if (!req.files?.length) {
    return res.status(400).json({ success: false, message: 'Please attach at least one image' });
  }

  res.status(201).json({
    success: true,
    count: req.files.length,
    data: req.files.map((f) => ({
      filename: f.filename,
      url: `${req.protocol}://${req.get('host')}/uploads/${f.filename}`,
    })),
  });
});

module.exports = router;
```

### `index.js`

```js
require('dotenv').config();
const express = require('express');
const path = require('path');
const multer = require('multer');
const cors = require('cors');

const authRoutes = require('./routes/authRoutes');
const uploadRoutes = require('./routes/uploadRoutes');

const app = express();

app.use(cors());
app.use(express.json());
app.use('/uploads', express.static(path.join(__dirname, 'uploads')));

app.use('/api/auth', authRoutes);
app.use('/api/upload', uploadRoutes);

// 404
app.use((req, res) => {
  res.status(404).json({ success: false, message: 'Route not found' });
});

// error handler (handles Multer errors too)
app.use((err, req, res, next) => {
  if (err instanceof multer.MulterError) {
    const msg = err.code === 'LIMIT_FILE_SIZE' ? 'File too large (max 2 MB)' : err.message;
    return res.status(400).json({ success: false, message: msg });
  }

  const status = err.statusCode || (err.message?.startsWith('Only') ? 400 : 500);
  res.status(status).json({ success: false, message: err.message });
});

app.listen(process.env.PORT || 3000, () => console.log('Server running'));
```

### Testing the flow in Postman

|#|Request|Setup|Expected|

|1|`POST {{baseUrl}}/api/auth/login`|JSON body with email + password; post-response script saves `token`|`200` + token|

|7|`POST {{baseUrl}}/api/upload/avatar`|form-data key typed `image` instead of `avatar`|`400` unexpected field|
|8|`POST {{baseUrl}}/api/upload/gallery`|form-data: 3 rows with key `photos`|`201`, `count: 3`|

## 8. Quick Reference

### Multer cheat sheet

```js
const multer = require('multer');

const storage = multer.diskStorage({
  destination: (req, file, cb) => cb(null, 'uploads/'),
  filename: (req, file, cb) => cb(null, Date.now() + path.extname(file.originalname)),
});

const upload = multer({
  storage,
  limits: { fileSize: 2 * 1024 * 1024 },
  fileFilter: (req, file, cb) =>
    file.mimetype.startsWith('image/') ? cb(null, true) : cb(new Error('Images only')),
});

app.post('/one',   upload.single('avatar'),      handler);   // req.file
app.post('/many',  upload.array('photos', 5),    handler);   // req.files
app.post('/mixed', upload.fields([{ name: 'a' }, { name: 'b' }]), handler);

app.use('/uploads', express.static('uploads'));
```

|Task|How|
|---|---|

### Common mistakes

|Mistake|Fix|
|---|---|
|Form has no `enctype="multipart/form-data"`|Add it, or use `FormData`|
|Field name mismatch (`avatar` vs `image`)|Match the client key and `upload.single('...')` exactly|
|Manually setting `Content-Type` for multipart|Remove it; the browser/Postman sets the boundary|
|Using `express.json()` for files|Use Multer|
|`req.file` undefined in Postman|Key type left as **Text**; switch it to **File**|
|No file size limit|Set `limits.fileSize`|
|Trusting `originalname`|Generate your own filename|
|Only checking file extension|Check MIME type (and ideally file content)|
|Upload folder missing|`fs.mkdirSync('uploads', { recursive: true })`|
|Committing `uploads/` to Git|Add to `.gitignore`|
|Saving files on ephemeral hosting|Use Cloudinary, S3, or similar|
|Auth middleware placed after Multer|Put `protect` first|
|Testing only the happy path|Also test 400, 401, 403, 404 cases|

### Summary

- **Multer** parses `multipart/form-data`, stores files with `diskStorage` or `memoryStorage`, and exposes `req.file` / `req.files` plus text fields in `req.body`.
- Always set **size limits**, a **file filter**, and **your own filenames**; serve uploads with `express.static`; use cloud storage in production.
- The frontend sends files using `FormData` (or an HTML form with `enctype="multipart/form-data"`).
- **Postman** lets you test every endpoint: JSON bodies, form-data uploads, Bearer tokens, environments and variables, automated tests, and collections.
